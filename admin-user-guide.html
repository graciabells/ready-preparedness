Admin User Guide

A simple guide to help administrators manage Ready Preparedness and keep residents informed, updated, and prepared for emergencies.

Welcome, Administrator!

This guide explains how to use the different features of the Ready Preparedness Admin Dashboard. Follow the instructions below when managing community information.

Dashboard Instructions

1. Admin Login

Access the administration portal using your authorized account.

  1. Open the Admin Login page.
  2. Enter your registered email address and password.
  3. Click the Login button.
  4. After successful login, the Admin Dashboard will open.

2. Dashboard Overview

View a quick summary of the information managed in the system.

  1. Open Dashboard from the sidebar.
  2. Check the total announcements.
  3. View the number of evacuation centers.
  4. Check the Go Bag and First Aid item counts.

3. Disaster Announcements

Create and update important information for residents.

  1. Open Announcements.
  2. Click Add Announcement.
  3. Enter the required announcement details.
  4. Save the information.
  5. Review the announcement to make sure it is correct and published.

4. Evacuation Centers

Maintain an updated list of designated evacuation locations.

  1. Open Evacuation Centers.
  2. Click Add Center.
  3. Enter the center name and required details.
  4. Save the entry.
  5. Update the information whenever necessary.

5. Emergency Hotlines

Keep emergency contact information accurate and accessible.

  1. Open Emergency Hotlines.
  2. Click Add Hotline.
  3. Enter the organization name and contact number.
  4. Save the information.
  5. Check that the phone number is correct and active.

6. Go Bag Checklist

Manage the emergency supplies displayed on the residents' page.

  1. Open Go Bag Checklist.
  2. Click Add Item to include a supply.
  3. Enter the item name and required image.
  4. Save the item.
  5. Edit or remove items when the list needs updating.

7. First Aid Kit

Maintain the list of basic first aid supplies for residents.

  1. Open First Aid Kit.
  2. Click Add Item.
  3. Enter the item name and required image.
  4. Save the item.
  5. Review the list and update it when needed.

8. Preparedness Guide

Provide residents with helpful disaster safety instructions.

  1. Open Preparedness Guide.
  2. Click Add Guide.
  3. Enter the guide title and instructions.
  4. Save the guide.
  5. Review the instructions for accuracy and clarity.

9. Weather Reminders

Share useful weather reminders and disaster-related updates.

  1. Open Weather Reminders.
  2. Click Add Reminder.
  3. Enter the reminder details.
  4. Save the information.
  5. Update reminders when conditions change.

10. Settings

Review the system information and administrator-related settings.

  1. Open Settings from the sidebar.
  2. Review the dashboard information.
  3. Manage account security through the authorized authentication process.
  4. Log out when finished using the dashboard.

Important Reminder

Always check the accuracy of announcements, emergency contact numbers, evacuation locations, and safety instructions before publishing them. Keep your administrator account private and never share your password with unauthorized individuals.
